Experiment 12: Port Scanning Tools
Aim: To identify open ports on a target system.
Theory / Explanation: Nmap performs a default scan of common ports. -sS performs a TCP SYN scan, which sends SYN probes and interprets responses to identify port states. Use only on systems for which permission has been granted.
Commands / Program:
•	nmap 192.168.1.1
•	nmap -sS 192.168.1.1
